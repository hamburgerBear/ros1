1. 简介
沿边控制器插件使用状态机组合控制算法，从而实现复杂的沿边控制功能。
常规状态为FollowWall和ApproachWall两种状态。
当碰撞事件和虚拟边界事件发生时，切换至Collision和FollowBoundary状态。
Forward状态，为辅助状态。用于协助ApproachWall、Collision状态，使动作更加流畅。

2. 数据管理
在整个控制插件中，主要可分为4种数据类型
 - 控制任务目标，如前进距离
 - 参数(特性)，如是否保持前行方向
以上两种数据通过控制算法setGoal(Args args)传入 
 - 只读数据，如代价地图、激光雷达数据
通过injector依赖注入器传入，状态机的Owner本身也是一种，依赖注入器。
但为了将数据传递至控制算法，需要再构建一个依赖注入器。
状态机是对控制算法的一层管理封装，控制插件也可以不需要这层封装，直接访问控制算法也可以。
或者通过行为树、或者通过if else、或者通过switch/map的方式。
 - 读写数据，读写数据的功能被封装在状态机的状态种，控制算法无法访问到。
通过状态机Root节点管理，如拟合数据、虚拟障碍物或禁区
